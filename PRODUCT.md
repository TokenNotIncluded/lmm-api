## Product Purpose

LMM Forge combines a multi-provider AI API gateway, a versioned MCP tool marketplace, and open-source bounty collaboration in one web console.

## Capabilities and Constraints

- The Go backend is the production default; the Rust backend and LMM setup CLI remain previews.
- Remote MCP publishing registers an existing public HTTPS service. It does not upload or host arbitrary serverless code.
- Loading tools and granting client invocation or spending permissions are separate actions.
- Successful paid calls credit creator earnings and configured platform fees to platform balances. Balances can be spent on models and tools; withdrawals are not supported.
- The platform fee is configurable. The hosted installation's selected rate must not become an immutable software-wide claim.
- Go and Web releases are independent; publication and deployment are distinct actions.
