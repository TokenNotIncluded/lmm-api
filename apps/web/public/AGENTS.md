# Agent rules for api.lmm.best

## Account registration

- Do not register accounts in bulk.
- Each user may create and use only one account on this site.
- Reuse the user's existing account. Do not create extra accounts to bypass limits or obtain repeated rewards.
- Do not register production accounts for automated tests.

## 注册规则

- 禁止批量注册本站账号。
- 每个用户只能创建和使用一个本站账号。
- 请使用用户已有的账号。不得通过额外账号绕过限制或重复领取奖励。
- 自动化测试不得在生产站点注册账号。
