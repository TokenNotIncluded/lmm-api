隐私政策

了解 API.LMM.BEST 如何处理与保护个人数据。

本隐私政策说明 API.LMM.BEST（“服务”）在提供 New API 网站、控制台和 API 时如何处理个人数据。服务由其实际运营者控制和运营；本页不虚构未披露的公司主体、地址或邮箱。

1. 适用范围与运营者 Scope and operator

本政策适用于您使用服务时的个人数据处理。实际运营者在适用数据保护法律下负责其处理活动；特定支付或上游服务商可能就其独立处理活动承担独立责任。

2. 我们可能收集的数据 Categories of data

  • 账户资料：注册、登录及账户管理所需的信息，例如账户标识、用户名及经您提供的联系信息。
  • 使用与技术数据：请求时间、用量、错误和安全日志、IP 地址、设备/浏览器信息、会话标识及防滥用信号。
  • 交易数据：订单、余额、付款状态和交易参考信息；完整支付卡信息通常由支付服务商处理。
  • API 内容：提示词、输入、文件、输出及相关元数据仅在技术上需要处理、传输、记录或按您选择的功能保存时处理。

3. 用途与处理依据 Purposes and bases

我们处理数据以提供、认证、保护、支持和改进服务；计算用量和处理支付；防止欺诈、滥用及安全事件；满足法律义务；以及在需要时征得同意。处理依据可包括履行与您的合同、遵守法律义务、保护合法利益（如网络与服务安全）或您的同意，具体取决于适用法律和场景。

4. 共享对象 Sharing

数据可在必要范围内与托管、监控、客户支持、安全、支付处理服务商及上游模型/API 提供商共享，以运行您请求的功能。接收方应受合同、其适用条款或法律义务约束。除非法律要求、为保护权利与安全、完成交易或经您指示，我们不以出售个人数据为目的提供数据。

5. Cookie 与类似技术 Cookies

服务可能使用必要的 Cookie、会话令牌或本地存储来维持登录、偏好、安全和基本分析。若法律要求同意，可通过相应的服务界面或浏览器设置管理；禁用必要技术可能影响服务功能。

6. 保存期限 Retention

账户、使用、交易及内容数据仅在提供服务、解决争议、维持安全、遵守法律或实现本政策目的所需期间保存。期限会随数据类型、功能设置、合同和法定义务而变化；到期后会删除、匿名化或按法律要求隔离保存。

7. 安全 Security

我们采取与风险相称的技术和组织措施，例如访问控制、传输保护、日志与监控。没有任何互联网传输或存储绝对安全；请保护自己的账户和 API 密钥，并及时报告疑似安全事件。

8. 跨境传输 International transfers

基础设施、支付服务商或上游模型提供商可能位于您所在司法辖区以外。发生跨境传输时，我们会在适用法律要求的范围内采取适当保障，例如合同承诺、认可的传输机制或其他合法措施。

9. 您的权利 Your rights

依适用法律，您可能有访问、更正、删除、限制或反对处理、数据可携带及撤回同意的权利，并可向主管机构投诉。要行使权利、申请删除账户或了解处理情况，请通过服务内已认证的支持/联系渠道提交请求；为保护账户和他人数据，可能需要验证身份。

10. 未成年人 Minors

服务并非面向不具备签订相关合同能力或适用法律禁止使用服务的未成年人。若发现未经适当授权收集了未成年人的个人数据，将在适用法律要求下采取合理措施处理。

11. 更新与联系 Changes and contact

我们可更新本政策并在本页标明新的生效日期；重大变更会在合理可行时通过服务内通知。隐私请求、账户删除或政策问题请使用服务内已认证的支持/联系渠道。
