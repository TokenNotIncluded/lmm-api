For application work, initialize the pinned source and use `generated/lmm-api-source/.agents/skills/README.md`. Its links and check commands resolve inside the implementation checkout. The [implementation skill index](https://github.com/TokenNotIncluded/lmm-api-source/blob/main/.agents/skills/README.md) lists available guides for UI, translations, packaging and verification.
