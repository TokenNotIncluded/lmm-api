# Scene brief

Copy this brief for each requested scene. Fill observed facts before coding.

- **Input:** user image, local video, verified public reference, or text.
- **Availability:** inspected / blocked. Record actual dimensions or duration.
- **Subject:** visible features only; do not identify people.
- **Position:** chapter and zero-based sequence index.
- **Silhouette:** proportions, negative spaces, contact points and focal details.
- **Geometry:** sampled surfaces, parts, material sources and approximate areas.
- **Motion:** rest → action → recovery; duration; local expressions or articulation.
- **Camera:** default yaw/pitch; permitted movement; unobserved sides.
- **Palette:** retain existing theme conversion; check dark surfaces on dark ground.
- **Budget:** expected point count and runtime allocations.
- **Verification:** finite data, immutable points, boundaries, contact, bounds and browser keyframes.
- **Status:** implemented changes, blocked references, exact checks and deployment state.

A broken video link is a blocked input, not permission to invent its contents.
