# 用户界面术语与导航

用户界面为同一概念使用同一主名称；路由、权限字段和历史数据标识不随显示名称重命名。

| 概念 | 英文主名称 | 中文主名称 |
| --- | --- | --- |
| 模型目录、可用性与价格 | Models and pricing | 模型与价格 |
| 开源贡献奖励 | Open-source bounties | 开源赏金 |
| 控制台帮助助手 | AI assistant | AI 助手 |
| 申请和审核 API 使用资格 | API access | API 访问权限 |

`Models` 可继续用于管理员的模型维护功能，与用户的“模型与价格”并非同一入口。`Challenges` 是独立的挑战业务，不能仅因名称相近将其全部替换成赏金。L0/L1/L2 作为补充等级信息展示，不替代能力描述。

登录后的主导航分为“使用 AI”“开发者”“生态”“账户”“其他服务”。管理功能在独立“管理员”区域；用户来源位于其“运营分析”之下。短信及临时邮箱激活属于“其他服务”。

底层 general、forge、personal 区域标识保留，防止无必要地改写已保存的配置；新加 developer 与 services 展示区域。后台的 console、chat、personal 权限开关仍按路由控制，展示分区不会改变授权。

当前 `/playground` 是进入配置助手的兼容重定向，不作为独立 Playground 宣传。余额、充值、套餐和邀请继续使用现有钱包及个人设置页面；不能创建没有对应功能的导航入口。
