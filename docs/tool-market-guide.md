# 工具市场使用与运行指南

工具市场运行在 Go 后端，复用现有账户、登录和站内余额。网页入口为 `/tool-market`，元 MCP 入口为 `/mcp/market`；原 `/mcp` 悬赏和 `/mcp/drawing` 绘图入口保持原用途。页面提供发现、发布、客户端连接与预算、调用及收益记录、管理员审核和超级管理员费率设置。

## 发布服务与版本

- 服务使用稳定 Tool 标识和不可变版本快照。每次保存生成新草稿版本；提交后不能直接改写，已发布版本不受草稿编辑影响。
- Remote MCP 发布连接既有公网 HTTPS 服务。作者可逐 Tool 设置固定价格、输入 token 用量价格或零价格；可信校验覆盖真实远端定义，用户请求不能伪造校验摘要。
- 公开、指定用户可见或收费服务需要管理员审核。经过可信校验、价格全为零且仅自己可见的 Remote 草稿可以由作者激活。管理员和超级管理员可以批准自己发布的服务；批准前仍须再次访问远端校验。
- 可见性支持公开、仅自己和指定用户；公开目录及详情在数据库查询中检查权限。支持名称、描述搜索及执行类型筛选，分页有上限。管理员暂停不能被作者恢复或发布新版本绕过。
- Bearer 或 API Key 认证的远端服务使用与所有者、端点和精确版本绑定的凭据。发现、校验、审核及执行使用同一凭据；凭据加密保存，不进入草稿 JSON、访问日志、schema 或反射结果。读取凭据配置只返回配置状态、模式及更新时间，不返回明文。
- 已提交和发布的版本不能原地改凭据。轮换凭据需要创建新草稿版本、校验并重新审核。第三方 OAuth 登录托管不受支持。

## 客户端与授权

- 收藏、按客户端加载、按 Tool 和精确版本授权分别保存。加载不授予调用或付款权限；发布新版本不会更新旧工具集或扩大旧授权。
- 元 MCP 每次请求校验身份并构建当前客户端的工具清单。管理能力包括搜索、详情、工具集加载/卸载和结果查询；业务工具只来自该客户端已加载且获对应版本授权的 Tool。服务状态、版本、工具集、账户及授权在正式执行前再次检查。客户端可刷新 `tools/list` 获取变化，不承诺所有客户端实时刷新。
- Pi/DSH 的 OAuth 配置可显式追加 `market:discover`，再按需追加 `market:invoke` 和 `market:manage`。必须重新授权；旧 token 与刷新流程不自动增加权限。已有 `market:discover` 和 `market:invoke` 授权的客户端可以首次加载工具并授权，不要求预先存在市场记录或追加 `market:manage`。LMM CLI 的只读 OAuth 配置不扩大权限。
- 手动 Bearer 客户端使用专用市场令牌。令牌绑定用户、客户端 ID、能力、有效期及用户安全版本，只保存摘要；明文仅在创建时返回，可撤销。它不是模型 API Key。OAuth 客户端 ID 为 `oauth:lmm-pi` 或 `oauth:lmm-dsh`，网页调用固定为 `web-market`，不能由请求体冒充其他客户端。
- 客户端 ID 按原始字符串精确匹配。MySQL 忽略大小写或重音的排序规则不能使令牌继承其他客户端的授权、结果和预算。安装及客户端预算发生既有主键的排序规则冲突时返回冲突，不覆盖另一客户端；卸载和断连也只作用于精确匹配的客户端。
- 授权限制包含有效期、单次价格上限、累计消费上限和成功次数上限；`max_calls` 必须显式为正数。账户、客户端、Tool 三级预算包含已冻结金额，调整预算不清空已有消费和冻结。预算为累计预算，不按日/月自动重置；零预算不允许付费消耗。
- 参数表单、JSON schema 及结果保留原始数字精度。超出 JavaScript 精度的默认值或已有参数通过高级 JSON 编辑，修改其他字段不能将其取整。金额换算按十进制整数进行。授权读取失败不当作空状态；运行前显示客户端及剩余限额，连接和账单读取失败提供重试。

客户端配置、令牌展示及断连语义见[连接与权限指南](tool-market-connections.md)。

## Remote 运行边界

- 仅允许 HTTPS 默认 443 端口；URL 中禁止用户密码、查询参数及片段。可使用平台保存的版本凭据进行 Bearer 或 API Key 认证，不托管第三方 OAuth 登录。连接使用专用 client，不受全局允许内网开关或代理环境变量影响。
- 实际拨号时解析 DNS，检查全部地址，再向已检查的 IP 拨号。拒绝私网、环回、链路本地、常见云元数据地址、保留地址及若干地址转换范围；禁止重定向，TLS 验证仍基于原主机名。
- 出站不携带 LMM 用户的 Authorization、Cookie 或代理凭证，只应用该远端版本明确配置的认证信息。不自动抓取结果中的链接或文件。
- 读取定义与校验只进行初始化和 `tools/list`，不执行业务 Tool。定义最多 100 个、最多 10 页；单个 schema 至多 16 KiB，响应至多 2 MiB。
- 支持对象型 JSON Schema、draft-07 / 2020-12 及本地 `#/...` 引用；不支持外部引用、动态引用或重新定义 schema 基址。参数大小与 JSON 深度有上限。
- 校验指纹覆盖名称、描述、输入/输出定义及行为提示。审核批准前再次校验，正式调用前再次获取定义并比较指纹。变化后须同步为新草稿并重新审核，不覆盖已审核配置。
- 仅支持同步最终结果。读取定义最多 20 秒，整个调用最多 45 秒，并发准入为每实例 32 个；这不是跨实例全局资源额度或长任务协议。
- MCP `isError`、输出 schema 不符、空结果及可识别的业务失败不按成功收费。受理、排队、执行中或不确定结果保留“未知”状态，不自动重复执行业务。

## 用量计费与举报

Remote 服务支持免费、按成功调用收固定费用，以及工具自报用量计费。
提供方自己保管上游 API key，市场不要求提供上游 key 或计量签名。
`tool_reported` 明确表示提供方自报，不承诺平台独立确认实际用量。

服务可以使用 `billing_mode = "metered"` 和 `billing_rules` 组合多项费用：

| metric | 整数用量单位 | 单价对应单位 |
| --- | --- | --- |
| `input_tokens` / `output_tokens` | token | 百万 token |
| `input_characters` / `output_characters` | Unicode 字符 | 千字符 |
| `images` | 张 | 张 |
| `audio_milliseconds` / `video_milliseconds` | 毫秒 | 秒 |
| `cpu_core_milliseconds` | CPU 核毫秒 | CPU 核秒 |
| `memory_mib_seconds` | MiB·秒 | GiB·秒 |
| `gpu_milliseconds` | GPU 毫秒 | GPU 秒 |
| `vm_milliseconds` | 虚拟机毫秒 | 虚拟机秒 |
| `storage_mib_seconds` | MiB·秒 | GiB·小时 |

每条规则设置 `metric`、`rate_quota` 和 `max_quantity`。单价为上述单位的整数钱包 quota。
每项实际费用单独向上取整至一个 quota，再求和；各项上限同样求和，形成 `price_quota` 最大预扣额。
数量必须为整数，不能超过该项上限或 10^12；不能重复计费项，也不能提交不受支持的单位。
例如 2 核运行 60 秒为 120 CPU 核秒，4 GiB 占用 60 秒为 240 GiB·秒。
CPU 核秒表示分配的 vCPU 容量乘实际运行时间；GPU 秒表示分配的 GPU 数乘实际运行时间。
内存与存储按实际分配容量和占用时间积分；采集器必须定义并记录其测量方法。

普通工具通过 `_meta.lmm_usage`、结果对象/structuredContent 的 `usage`，或文本 JSON 的 `usage` 上报。
Jev 的 `usage.input_tokens` 可直接读取。平台仅接受价格快照所需的整数单位，校验缺失、
负数、null、重复 JSON 键、超过上限及多来源不一致；这些情况不收费并释放预扣。
工具返回的单价和总价不能覆盖当次已审核价格，明确的零用量收费为零。
协议和可选签名回执见[用量计费配置](tool-market-metering.md)。

最终结果及格式校验后的用量先持久化，再按实际上报量结算，退还未使用的预扣，更新授权、预算和划转。
重复请求和恢复只使用已经记录的结果，不再次执行上游任务。
升级前的未认证结果既没有新来源也没有验证标记，不能被恢复任务自动结算；到期释放预扣。
共享数据库执行和恢复节点应一起升级，以保持一致的协议和证据字段。

用户在账单或调用结果中点击举报，说明怀疑有误的用量或费用。
账单证据独立于一小时后过期的原始结果保留。每笔调用一份举报，只有付款人能提交。
管理员审核自己未参与的账单，确认造假后停用服务，商家不能自行解除停用；驳回需填写原因。
举报不会自动逆转已结算资金或重写余额，资金争议需要另行处理。

本功能只结算一次同步调用完成的任务，仍受 45 秒执行期限限制。
创建后持续运行的虚拟机、按小时续费的存储、跨调用累计账单和自动停机不是已实现功能。
这些场景需要独立的资源租约、周期性计量及余额不足后的回收机制，不能用 `vm_create` 返回的自报时长替代。

## 资金、调用与结果恢复

金额使用现有整数 `quota` 单位，时间使用 Unix 秒。`fee_bps` 为万分比，`1250` 表示 12.5%。平台费率及收款账户由超级管理员配置，收款账户须为有效超级管理员。配置记录不存在时预扣失败关闭；启用配置不能绕过版本校验、发布、工具集或授权门槛。

- 先验证参数、远端定义及完整权限，再持久化预扣余额和多级预算；模型与工具调用共同使用同一余额。只有取得数据库唯一执行权后才能发送业务调用，首次取得执行权才返回 `started=true`。
- 客户端必须提供业务 `request_id`。调用 ID 按用户、客户端和业务标识确定；重复请求查询原记录，不再次接触远端或扣费。相同标识混用 Tool、版本、授权或参数会被拒绝。参数只保存摘要。
- 执行状态与结算状态分开，包含预留、执行中、结果未知、成功、失败和未执行取消。失败释放冻结；未知结果到期释放资金但保留未知执行状态。释放后不允许补扣。
- 最终结果先独立持久化，再原子提交作者入账、平台入账、划转流水和结算状态。费率与收款账户使用预扣时快照；手续费按整数额度向下取整，作者取得剩余金额。零价格调用不产生作者收入或平台手续费；同一账户兼任作者、平台收款方时仍按原调用总额记账。
- 结算暂时失败时，恢复任务依据已保存结果继续处理，不重新执行业务。默认待确认期限为预扣后 120 秒；主节点的系统任务调度器每 15 秒检查，用户查询到期调用时也立即尝试释放。关闭新交易不关闭已有调用恢复。
- 结果保存一小时，按原用户及客户端控制读取，与日志和作者统计隔离。到期清理结果内容，保留调用与划转记录；重复领取不收费。结果写入错误日志不输出完整 SQL 参数。
- 成功收入直接进入既有站内余额，可用于模型和其他工具消费；没有提现、打款或待结算收益池。冻结释放不等于成交退款；已结算退款、部分冲正、争议及收益追回不受支持。
- 草稿、授权、预算、配置、审核及结算保留审计记录。用户可查询自己的调用和收入；作者收益接口不返回调用者身份、参数摘要或完整调用内容。
- MySQL 市场事务使用局部 `READ COMMITTED`，通过服务及账户行锁串行处理授权、预留和结算，避免等待锁后的旧快照覆盖计数或通过已撤销授权。其他业务事务、会话默认隔离级别及 PostgreSQL/SQLite 不受影响。MySQL binlog 使用 `ROW` 或 `MIXED`，不能使用 `STATEMENT`；参见 [MySQL 8.4 隔离级别说明](https://dev.mysql.com/doc/refman/8.4/en/innodb-transaction-isolation-levels.html)。

## 免费内置工具与绘图结算

绘图、钱包及开源悬赏工具由迁移写入节点注册为可校验服务，工具调用价格为零。绘图模型仍按原规则收费；钱包转账移动实际余额并在需要时确认操作，钱包工具也可生成充值链接、转账链接及二维码。见[钱包工具说明](wallet-mcp.md)。

内置工具经 `/mcp/market` 和网页市场执行，沿用精确版本、客户端、工具授权、次数、有效期及幂等检查。暂停新的 Remote 交易不影响这些可信内置工具。网页及元 MCP 沿用可信代理规则传递客户端 IP，绘图 API Key 的 IP 限制仍生效，不接受非可信代理伪造的转发头。

市场绘图保存一份结构化图像结果，网页使用 Blob 预览和下载，不重复将 base64 展开为文本。绘图响应上限取配置的 relay 上限与 32 MiB 的较小值，保留结果另留 64 KiB MCP 包装空间；其他内置和 Remote 结果至多 2 MiB。MySQL 的结果及确认数据使用 LONGTEXT，PostgreSQL/SQLite 使用 TEXT。

确认后的绘图在正常模型结算前校验可用图像并持久化待结算结果。结果可按原用户和客户端取回，但 `builtin_billing_pending` 阻止成功结算、恢复扫描及到期释放将其误报为成功。正常模型结算成功后才完成市场调用。模型结算失败或完成标记写入失败时保留图像及待确认状态，不再次生成，也不把已提交模型费用当作普通失败退款。持久化或输出校验失败走既有异步退款路径；模型计费与市场记录不构成跨系统原子事务。

## HTTP 接口

基础路径为 `/api/tool-market`，返回值沿用 `success/data`；错误使用固定错误码，不直接暴露内部数据库错误。账户身份来自认证，不接受请求体自报。除公开目录、配置及详情外，接口要求登录，并继续实施相应所有权或管理权限检查。

| 方法与路径 | 权限与用途 |
| --- | --- |
| `GET` 基础路径（无尾斜杠） | 可匿名查询公开目录；登录后包含获准访问的已发布服务。参数为 `q`、`execution_type`、`offset`、`limit`。 |
| `GET /config` | 公开读取开关、费率、收款账户、额度单位及协议限制。 |
| `GET /services/:id` | 在可见范围内获取已发布详情。 |
| `POST /inspect` | 登录用户只读获取 Remote MCP 定义，支持所配置的远端凭据。 |
| `POST /services` | 登录用户创建草稿。 |
| `GET /services/:id/draft` | 作者读取草稿。 |
| `PUT /services/:id/draft` | 作者保存新的草稿版本。 |
| `GET /services/:id/credentials` | 作者查询指定 `version_id` 的凭据配置状态，不回显秘密。 |
| `PUT /services/:id/credentials` | 作者为草稿版本配置与端点绑定的远端凭据。 |

| `POST /services/:id/review` | 管理员审核指定版本；批准须有可信校验，管理员和超级管理员可以批准自己的服务。 |

| `PUT /budgets` | 设置 `account/client/tool` 累计预算。 |
| `GET /mine/:kind` | 分页查询本人的 `services/grants/installations/budgets/favorites/tokens/oauth-clients`。 |
| `POST /invoke` | 网页客户端执行已加载且获授权的 Tool，不接受用户自报结果。 |

| `GET /income` | 查询本人的入账流水。 |

| `POST /clients/disconnect` | 原子撤销本人的指定客户端令牌和授权，并卸载工具；不取消已受理调用。详见连接指南。 |
| `DELETE /tokens/:id/record` | 仅从列表移除本人已撤销连接令牌；保留令牌摘要及撤销记录。 |
| `POST /clients/remove` | 本人指定客户端的令牌和授权全部撤销后，移除列表记录并卸载工具；调用、使用和预算不变。 |
| `PUT /config` | 超级管理员设置开关、费率及唯一收款账户。 |

## 内部执行约定

`ReserveToolMarketCall`、`StartToolMarketCall`、`FinishToolMarketCall`、`MarkToolMarketCallUnknown` 和 `ExpireToolMarketCall` 是内部函数，没有 reserve/start/settle HTTP 资金操作接口。可信执行适配器须按顺序：

1. 验证身份，从可信 OAuth/客户端身份取得用户和客户端，不信任调用参数自报身份。
2. 根据已审核版本验证参数及完整权限；草稿结构检查不能代替 JSON Schema 或远端兼容性校验。
3. 预扣并持久化记录，重复请求只返回原状态。
4. 取得唯一执行权后发送远端请求；数据库无法可靠确认时停止，不先执行后补账。
5. 验证最终业务结果后结算；HTTP 200、受理或进度不是成功依据。
6. 不重放结果未知的副作用操作，由恢复任务核实或到期释放。执行权提交与远端接收之间仍有网络不确定性，不能保证远端绝对只执行一次。

内部 `resolve_by` 须在未来 24 小时内，公开执行适配器采用前述默认待确认期限。不能人工将未校验草稿改为已校验或已发布来绕过流程。

## 部署与回滚

数据库变更通过正常或快速迁移路径执行。使用认证 Remote 服务的所有共享数据库执行节点必须配置同一稳定的 `TOOL_MARKET_ENCRYPTION_KEY`。

首次升级到支持绘图待结算状态的版本时，必须停止旧调用并排空请求，再迁移数据库、升级全部共享数据库 API 节点及调用恢复 worker。旧 worker 不识别 `builtin_billing_pending`，不能与新版本混用滚动运行；关闭 Remote 交易不能代替停止旧恢复任务。该字段默认 false，既有结果保持原状态。

回滚前先排空执行和恢复任务，核对正常模型账本并处理全部待结算绘图，不能清除标记冒充结算完成。保留 `builtin_billing_pending` 和 MySQL LONGTEXT；旧二进制的 apply 迁移可能将 LONGTEXT 缩回 TEXT，禁止自动 schema 降级。确需缩列时先备份或清理超出 TEXT 容量的结果，再单独迁移。

## 支持范围与复跑验证

市场不支持 Serverless 文件上传或 WASM 运行时、第三方 OAuth 登录托管、长任务及取消协议、免费试用规则、周期预算、价格定时生效、作者/工具/活动专属费率、成交退款及争议处理。市场使用逐 Tool 固定价格或输入 token 用量价格，以及单一全局费率；Rust 预览后端不具备该业务的完整同步实现。

固定 HTTPS MCP 服务、端到端调用及 PostgreSQL/MySQL 隔离并发验证的运行方式见[付费测试服务说明](tool-market-paid-test-mcp.md)。该服务用于重复验证协议、授权和结算规则；测试结果不代替真实编辑器 OAuth、生产凭据配置、第三方调用或生产部署验收。


## 工具退休与旧后端兼容

删除服务仅阻止发现、编辑、审核、重新激活和新调用。不可变版本、工具、授权、调用、结果、举报与资金划转都保留；已开始的调用按冻结价格继续结算，尚未开始的预留可释放。

退休事务写入现有字段 `status=deleted`、空 `live_version_id`，并把 `draft_version_id` 置为保留 UUIDv5 `5ccac1a6-3c42-5e56-9ab3-47c234d77a2e`。该值是永久退休标记，没有对应草稿版本；普通版本仍使用 UUIDv4。原指针记录在删除审计事件中。无需新增表、列或删除历史数据。

旧 Go86/Go87 的编辑读取会拒绝这个非解析草稿指针，激活因空 live 指针失败，审核和 AI 结果因版本指针不匹配失败。旧举报审核可能将状态改为 suspended，但不会移除退休指针；新版同时识别指针并继续隐藏、拒绝写入。旧版“我的服务”仍可能显示退休元数据，这是只读 UI 残留，不表示工具恢复可用。

验证使用 ea0705 旧生产源码加独立 test-only 退休状态 fixture，检查实际旧业务函数和 19 张业务/钱包表。此源码兼容验证不替代正式双节点或二进制回滚演练。不得把退休标记改回普通草稿或清掉它冒充清理。
