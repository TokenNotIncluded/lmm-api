# 内置助手的管理执行与权限边界

管理员可以在开启 Agent 工具循环后，通过对话要求助手读取配置、模型定价、渠道、用户和套餐等状态。受支持的管理变更由助手生成预览，管理员在界面中明确确认后应用，并可继续读取结果完成核验。权限范围与当前登录账户一致：普通管理员不会获得超级管理员权限，普通用户不会获得管理能力。

## 管理工具

- `list_admin_operations`：从当前 Go 服务实际注册的 `AdminAuth` / `RootAuth` 路由生成目录，支持搜索与分页。指定 `operation_id` 可读取对应的请求字段、路径参数和查询参数说明。
- `execute_admin_operation`：仅执行目录中经过审查的只读操作，接收精确操作 ID、路径参数、查询参数及接口声明的 JSON 请求体，在进程内重新经过完整路由链执行。写操作会被拒绝，包括有副作用的 GET 接口。模型不能设置目标 URL、认证头或执行身份。
- `audit_admin_model_pricing`：分页检查启用模型的基础价格、异常或缺失倍率、零价、固定价与 token 计费冲突、分组倍率及动态定价成本覆盖。必须翻完所有分页后才能声称检查完成；成本覆盖不代表已经验证利润。
- 既有 `prepare_admin_*` 工具生成配置、定价、渠道、模型同步或用户技能变更的预览。管理员必须在界面中明确确认，服务器才会消费绑定当前用户和会话的单次签名令牌，并应用预览中的变更。模型工具调用不会自动执行这些变更。

管理目录也会列出写操作及其字段说明，但通用执行工具始终保持只读。尚无专用确认流程的变更，例如套餐修改，应由管理员在对应控制台页面完成。

常用请求示例：

- “检查全部启用模型的定价，列出缺失项和异常倍率，先不要修改。”
- “把模型 X 的输入倍率改为 0.8，输出倍率改为 4，修改后重新读取核对。”
- “查找渠道 12 的状态，生成停用预览，确认后检查路由结果。”
- “查看现有套餐，指出要修改的字段和对应的控制台页面。”

配置、定价及专用模型同步仍要求 ROOT。渠道操作继续检查 `ChannelRead`、`ChannelWrite`、`ChannelOperate` 等细分权限。验证码、通行密钥、二次验证等步骤由原接口继续执行，助手不能替用户制造验证凭证。密钥和会话凭证不会作为工具查询结果交给模型。

## 执行安全

每次管理工具调用会重新读取数据库中的账户角色、启用状态和会话状态、安全版本及有效期。执行与审计使用原登录用户的身份；给模型请求出资的账户只承担计费。管理员接口也重新读取当前账户信息，避免缓存中的旧 ROOT 角色在降权后继续生效。

管理目录来自实际路由注册，执行时还检查 Gin 最终匹配的路由模板。这样可以阻止把 `:id` 填成 `search` 等静态路径，借参数切换到另一接口。原有角色限制、业务校验、细分权限、限流、二次验证和审计都会执行。助手调用有独立的 16 KiB 请求限制和 128 KiB 响应捕获限制。

HTTP 请求字段说明通过 `cmd/assistant-contracts` 从本仓库 Go 源码生成，并由漂移测试检查。字段说明用于指导请求；最终仍由原控制器实施业务校验。目录会明确标记无法完整推导的请求格式。二进制、流式或过大的响应会报告限制及执行结果的不确定性，不能把这类响应描述为已完成验证。

工具结果递归清除凭证、请求头、敏感渠道设置、配置中的秘密值及文本内的秘密。工具轨迹只保留有限的操作元数据，每次管理调用独立显示，后续成功不会抹去其他操作的失败。

## 循环与上下文

默认每次请求最多 12 个模型轮次、90 秒；可配置为 1–32 轮和 5–300 秒。已有持久化设置不会被默认值覆盖，升级后可在助手设置中调整。最后一轮留给结果说明，每轮最多实际执行 4 个工具；超出的调用获得明确的“未执行”结果，可在后续轮次继续。

循环会修复缺失或重复的工具调用 ID，对参数标准化后拦截重复成功或结果不确定的非只读工具调用。读取可以再次执行，以便验证。收到浏览器自动重试请求时，非只读管理工具调用会被拦截，读取仍可用于核对；相关工具调用后的回答错误会返回不可自动重试状态。这些保护不代替管理员的界面确认。确认令牌只能消费一次；遇到确认请求断线或结果不确定时，应检查实时状态，避免重复提交同一变更。

上下文压缩使用确定性的摘录和截断标记，保留系统规则、当前用户请求、最近完整的工具调用与结果。旧工具调用与结果整体处理，不会形成孤立结果，也不会把摘要提升为系统指令。明确的上游上下文窗口错误最多触发两次进一步压缩尝试。必要上下文本身过大时会明确失败。

会话历史只从服务器按归属恢复。浏览器提交的旧助手回答、工具调用字段、负数会话 ID 无法用于伪造执行历史。较长历史保留近期完整轮次和标记过的早期摘录；资格、权限和奖励判断使用未压缩的服务器历史。管理员回答不使用普通问答缓存。

## 验证与维护

```sh
cd apps/api-go
go generate ./controller
go test ./controller ./router ./middleware ./internal/agent ./internal/assistantcontracts ./setting
```

新增管理端路由应继续使用现有 `AdminAuth` / `RootAuth` 注册方式，并重新生成请求字段说明。新增有副作用的 GET 接口需要保持为写操作分类；新增纯读取接口应加入经过审查的读取列表，以支持修改后的重复验证。

这些更改作用于内置助手所在的 Go 服务；没有调用线上模型、修改生产配置或自动部署。
