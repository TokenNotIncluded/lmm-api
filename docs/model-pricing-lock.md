# 模型价格锁

在「设置 → 模型定价」中，每个模型的价格旁都有锁按钮，默认解锁。点击锁定会立即保存锁状态，并保留该模型已经保存的定价。解锁后可以继续编辑和保存。

锁定覆盖该模型的按次价格、输入输出倍率、缓存和图片/音频倍率，以及计费模式和阶梯表达式。锁定时，该模型尚未保存的修改会被丢弃并提示警告，其他模型的草稿保留。

价格锁由 Go 服务统一执行。单项保存、批量保存、JSON 导入、上游倍率同步、恢复默认和内置助手的定价写入都经过同一保护。修改或删除已锁定模型的定价时，保留原值，返回成功响应和 `warnings`，其余有效修改继续保存。解锁与修改价格需要分两次请求执行；同一批请求中的价格仍受原来的锁保护。

```json
{
  "success": true,
  "message": "",
  "warnings": ["模型 example-model 的价格已锁定，已忽略本次价格修改"]
}
```

锁状态存储于 `ModelPriceLock` 配置，值是 JSON 字符串，例如 `{"example-model":true}`；缺省值为 `{}`。沿用原设置接口的超级管理员权限。助手应读取警告和保存后的配置，准确报告被忽略的修改。

对于使用共享通配符价格的模型，锁会同时保护其实际引用的定价条目。分组倍率、动态定价因子和渠道成本属于独立配置，价格锁保护模型基础定价，不冻结这些配置的计算结果。

当前功能用于生产默认的 Go 服务；Rust 预览服务尚未实现价格锁。
