# 工具市场实施记录

## 第二批：Remote、元 MCP 和页面已接通

当前增量已接通公开、无需凭证的 Remote MCP：读取定义 → 保存草稿 → 校验 → 管理员重新校验并审核发布 → 用户加载 → 单独授权 → 执行 → 成功划转 → 查询原调用与结果。下方“第一批”的未接通清单是历史记录，以本节为最新进度。

### 入口与权限

- 页面：`/tool-market`，复用现有账户登录和控制台组件，包含发现、发布草稿、我的发布、客户端连接与预算、调用及收益记录、管理员审核、超级管理员费率设置。七种语言的新增文案均通过项目翻译脚本写入。
- 元 MCP：`/mcp/market`。原 `/mcp` 悬赏和 `/mcp/drawing` 绘图入口保持原用途。
- 元 MCP 每次请求校验身份并构建当前客户端的工具清单。管理能力包括搜索、详情、工具集加载/卸载和调用结果查询；业务工具仅来自此客户端已加载并拥有对应版本授权的 Tool。加载不创建付费授权。
- Pi/DSH 的既有 OAuth 原生配置可以显式追加 `market:discover`，再按需追加 `market:invoke` 与 `market:manage`。必须重新授权；旧 token 与刷新流程不会自动增加权限。授权页面逐项显示市场权限。LMM CLI 原有只读 OAuth 配置没有扩大。
- 兼容手动 Bearer 配置的客户端可以使用页面创建的专用市场令牌。令牌绑定用户、客户端 ID、能力、有效期和用户安全版本；保存摘要，明文只在创建时返回，支持撤销。它不是其他业务的 API Key。OAuth 工具集客户端 ID 使用 `oauth:lmm-pi` 或 `oauth:lmm-dsh`；网页调用固定为 `web-market`，不能由请求体冒充其他客户端。
- 服务状态、版本、工具集及授权在正式执行前再次检查。支持刷新 `tools/list` 获取工具集变化，不承诺所有客户端实时刷新。

### Remote 运行边界

- 仅 HTTPS 默认 443 端口，禁止 URL 中的用户密码、查询参数和片段；不接入需要 OAuth/API Key 的第三方服务。网络连接使用专用 client，不受全局允许内网开关或代理环境变量影响。
- DNS 解析在实际拨号时进行，检查全部地址，并向已经检查的 IP 拨号。拒绝私网、环回、链路本地、云元数据常见地址、保留地址及若干地址转换范围；禁止重定向。正常 TLS 验证仍基于原主机名。
- 出站不携带 LMM Authorization、Cookie 或代理凭证。不会自动抓取返回内容中的链接或文件。
- 读取定义与校验只做初始化和 `tools/list`，不触发业务 Tool。定义最多 100 个，最多 10 页；单个 schema 至多 16 KiB，响应至多 2 MiB。
- 当前支持对象型 JSON Schema、draft-07 / 2020-12，以及本地 `#/...` 引用；不支持外部引用、动态引用或重新定义 schema 基址。参数大小和 JSON 深度有上限。
- 校验保存实际远端工具的指纹，覆盖名称、描述、输入/输出定义和行为提示。审核批准前重新校验；每次正式调用前重新获取定义并比较指纹。变化后需同步为新草稿并重新审核，不覆盖当前已审核配置。
- 本阶段仅支持同步最终结果：读取定义最多 20 秒，整个调用最多 45 秒；并发准入为每实例 32 个。它不是跨实例全局资源额度，也不是长任务协议支持。
- MCP `isError`、输出 schema 不符、空结果，以及可识别的业务失败状态均不按成功收费。受理/排队/执行中结果或调用结果不确定时保留“未知”状态，不自动重复执行。

### 资金与结果恢复

- 先检查参数和远端定义，再预留余额与预算。只有取得数据库唯一执行权后才发送业务调用。
- 客户端必须给出业务 `request_id`；重复请求先查原记录，不再次接触远端，不再次扣费。相同标识混用内容会被拒绝。
- 最终结果先独立持久化，再尝试原子结算；结算暂时失败可以由恢复任务根据已记录结果继续处理，而不是重新执行业务。
- 默认结果待确认期限为预扣后 120 秒。恢复任务通过既有系统任务调度器每 15 秒检查，依赖主节点运行；用户查询到期调用时也会立即尝试释放，不必等待下轮扫描。超过期限释放冻结金额，之后不能未经授权补扣。关闭新交易不关闭已有调用的恢复。
- 结果保存一小时，按用户和客户端控制读取，并与日志/作者统计隔离。到期清理结果内容，保留调用与划转记录；重复领取结果不收费。结果写入的错误日志不输出完整 SQL 参数。
- 成功后直接向作者和指定平台账户划转。没有提现、打款或待结算收益池。失败释放与成交退款仍是不同流程：已结算退款、部分冲正、争议和收益追回尚未实现。

基础路径仍为 `/api/tool-market`：

| 方法与路径 | 用途 |

### 验证与未完成范围

本地 HTTPS MCP 测试走真实 MCP SDK 协议，覆盖读取/校验不执行业务、发布后调用、成功划转、业务错误、输出格式错误、未知及中间结果、定义变化、重试不重放和到期恢复。元 MCP 集成测试覆盖身份绑定、加载与授权分离、清单刷新、参数 schema 引用、令牌撤销以及安全版本失效。OAuth 测试验证必须显式新增市场权限，旧授权不扩大。

前端金额换算按十进制整数计算，测试最小额度、不可表示的小数及最大安全整数。浏览器检查使用明确标注的隔离数据，覆盖桌面/手机视图与交互；这不是生产数据或真实第三方工具的验收。界面复核后的修正包括授权读取失败不冒充空状态、运行前显示客户端与剩余限额、连接和账单读取失败提供重试。

仍未实现：第三方 OAuth/Secret 托管、Serverless 文件与运行时、真正的长任务/取消协议、免费试用规则、周期预算、成交退款与争议、完整作者经营统计、推广和 Rust 后端同步。真实外部客户端兼容矩阵、PostgreSQL 多连接故障注入及生产部署未验收。本批没有发布到服务器。

## 第一批：后端业务基础

本批接入 Go 后端，复用现有用户余额。遵循本次需求调整：成功调用直接向作者与平台收款账户划转，保存划转记录；不建设提现或作者待结算收益池。

### 已实现

- 服务、稳定 Tool 标识、不可变版本快照。每次保存生成新草稿版本；提交后不能直接改写，已发布版本不受草稿编辑影响。
- 草稿保存、读取、提交、审核状态转换。发布必须有与版本摘要一致的可信校验结果；用户请求不能写入校验结果。管理员暂停不会被作者恢复或发布新版本绕过。
- 公开、仅自己、指定用户可见；公开目录和详情在数据库查询中检查权限。支持名称/描述搜索和执行类型筛选，分页有上限。
- 收藏、按客户端加载、按 Tool 和精确版本授权分别存储。加载不会自动授权，发布新版本不会更新旧工具集或扩大旧授权。
- 授权的有效期、撤销、单次价格上限、累计消费上限、成功次数上限；账户、客户端、Tool 三级累计预算。
- 持久化调用预扣。预算包含已冻结金额；新建或调整预算不会清空既有消费与冻结。与模型预扣共同使用同一数据库余额。
- 调用 ID 按用户、客户端、业务请求标识确定；重放返回原记录。相同请求标识携带不同 Tool、版本、授权或参数时拒绝。参数只保存摘要。
- 执行前再次检查工具状态、工具集、账户和授权。只有第一次成功取得执行权的后端调用才返回 `started=true`。
- 执行状态与结算状态分开。支持预留、执行中、结果未知、成功、失败、未执行取消；失败释放冻结，未知状态到期释放资金但保留未知执行状态。释放后拒绝再扣款。
- 成功结算原子提交作者入账、平台入账、划转流水和调用结算状态。费率与收款账户使用调用时快照。按整数额度计算，手续费向下取整，作者取得剩余金额。
- 零价格调用不产生作者收入或平台手续费。同一账户同时是作者、平台收款方时仍按原调用总额记账。
- 草稿、授权、预算、配置、审核与结算审计记录；自己的调用记录和收益流水查询。作者收益接口不返回调用者身份、参数摘要或完整调用内容。
- 注册正常、快速两条数据库迁移路径，沿用仓库启动迁移与验证机制。

### 当前接口

基础路径：`/api/tool-market`。返回值沿用 `success/data`；错误提供固定错误码，内部数据库错误不直接暴露。

| 方法与路径 | 权限与用途 |
| --- | --- |
| `GET /`（实际无尾斜杠） | 可匿名查询公开目录；登录后包含获准访问的已发布服务。参数 `q`、`execution_type`、`offset`、`limit`。 |
| `GET /services/:id` | 在当前可见范围内获取已发布详情。 |
| `POST /services` | 登录用户创建草稿。 |
| `GET /services/:id/draft` | 作者读取当前草稿。 |
| `PUT /services/:id/draft` | 作者保存新的草稿版本。 |
| `POST /services/:id/submit` | 作者提交指定 `version_id`。 |
| `POST /services/:id/review` | 管理员审核指定版本；未经可信校验不能批准。 |
| `PUT /services/:id/favorite` | 保存或取消收藏。 |
| `PUT /installations` | 为 `client_id` 加载或卸载指定 `tool_id/version_id`。 |
| `POST /grants` | 为精确客户端、Tool、版本创建有次数、金额、有效期上限的授权。 |
| `DELETE /grants/:id` | 撤销自己的授权。 |
| `PUT /budgets` | 设置 `account/client/tool` 的累计预算。 |
| `GET /mine/:kind` | 分页读取自己的 `services/grants/installations/budgets/favorites`。 |
| `GET /calls` | 分页读取自己的调用记录。 |
| `GET /income` | 分页读取自己的入账流水。 |
| `PUT /config` | 超级管理员设置启用状态、费率和唯一收款账户；收款账户须为有效超级管理员。 |

金额统一使用现有整数 `quota` 单位。`fee_bps` 为万分比，`1250` 表示 12.5%。时间字段使用 Unix 秒。当前预算为累计预算，不含日/月自动重置；设置为零表示不允许付费消耗。授权的 `max_calls` 必须显式为正数。

### 后端执行接入约定

`ReserveToolMarketCall`、`StartToolMarketCall`、`FinishToolMarketCall`、`MarkToolMarketCallUnknown`、`ExpireToolMarketCall` 是内部函数，没有开放为 HTTP 资金操作接口。

后续执行器须按顺序完成：

1. 身份验证，并从可信 OAuth/客户端身份取得用户与客户端；不能信任调用参数自报身份。
2. 根据已审核版本验证参数及完整权限。当前草稿结构检查不等于 JSON Schema 完整验证，也不等于远端兼容性校验。
3. 预扣并持久化调用记录；重复请求只返回原状态，不重新执行。
4. 取得唯一执行权，再发送远端请求。数据库无法可靠确认时停止，不允许先执行后补账。
5. 验证最终业务结果后结算；仅受理、进度、中间结果或 HTTP 200 不能作为成功依据。
6. 结果未知时不重放副作用操作，由恢复任务核实或到期释放。执行权提交与远端接收之间的网络不确定性不能宣称为远端绝对只执行一次。

成功入账即进入既有站内余额，没有提现入口。用户已经付费成功后的退款，需另接原划转冲正和追回规则；本批的“释放”仅针对尚未结算的冻结金额，不能冒充成交退款。

### 尚未接通的功能

这批是可测试的后端基础，不是可上线的完整工具市场。

- Remote 安全连接、Tool 同步、可信校验、执行适配、第三方 OAuth 与 Secret 管理尚未接入。生产代码没有签发 `validation_digest` 的入口，所以新草稿不能上架。
- 元 MCP 动态工具清单、细分 OAuth scope、客户端互通、网页市场、发布表单、作者后台和 WebMCP 发布辅助尚未接入。
- 调用恢复调度器、结果保存与领取、取消协议、已结算退款/争议处理尚未接入。`resolve_by` 当前由可信内部调用方传入，限制在未来 24 小时内；最终公开处理期限仍需由平台配置统一管理。
- 免费试用额度、周期预算、价格定时生效、作者/工具/活动专属费率和完整市场统计尚未接入。当前只支持版本内固定逐 Tool 价格、零价格和单一全局费率。
- Serverless 目前只保留草稿执行类型，没有上传、WASM 运行时、资源预算或执行权限实现。
- Rust 预览后端尚未同步新增业务。

配置记录不存在时执行预扣失败关闭。即使配置启用，也不能绕过版本校验、发布、工具集或授权门槛。不要为了演示人工把数据库草稿改成已校验或已发布。

### 验证边界

新增模型与路由测试覆盖价格快照、整数边界、重复调用、原子划转失败回滚、冻结计入多级预算、模型与工具余额竞争、授权撤销、私有目录、版本变更、未校验禁止发布、管理员暂停、跨账户读取以及伪造状态不能结算。

并发用例使用 SQLite 单连接的事务串行化，配合 Go race 检查；它们验证应用层防重和数据竞争，不代替 PostgreSQL 多连接锁竞争、真实远端执行与生产故障恢复验证。
