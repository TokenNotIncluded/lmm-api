# 历史文档的使用范围

根目录指南、架构、开发、Docker、协议和打包文档以当前微服务分支为准。旧升级和部署指南已移除可执行步骤，保留原路径作为历史入口，原文固定到退役前的源码提交，避免误用。

仍保留的旧商店、模型、支付、工具和前端专题，是行为设计及接入参考，不表示新宿主已经提供相同 API。以当前路由注册、模块源码和对应提交的测试为准。不要根据历史文档创建生产迁移任务。

保留历史事故、安全记录、许可证、公开接口说明和已有线上包的签名验证工具。它们不是“未使用即删除”的临时文件。确认最后一个使用方已经退役后，才删除代码、协议或分发资源。

旧实现可以在 Git 历史中查看；不通过复制旧表、恢复旧单体入口或清空数据库来完成新安装。返回[文档目录](README.md)。
