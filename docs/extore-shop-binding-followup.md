## 最终体验与安全条件

商城点击导入 → 自动跳转 Extore → 未登录先登录 → 勾选商品并批准 →
自动导入所有规格 → 返回商城商品列表。

- 超级管理员可选择所有店铺商品；店长只可访问自己的店铺。
- 导入商品显示来源、同步按钮和上次同步时间。
- 重复同步更新原商品和规格，不重复创建。
- Extore 是商品配置的真相源。商城所有商品和规格配置都须能在 Extore
  配置并一一对应；导入商品不得通过商城编辑绕过上游配置。
- 展示卡密状态、数量；同步不自动发行或补货卡密，保留原有发行权限、
  额度和幂等保护。
- 连接撤销、到期和跨店铺隔离须有效。
- 凭据仅由后端加密保存，不回传浏览器、不写日志。
