# 前端设计规范

## Overview

当前方向是暖白底色、墨黑文字、少边框、多留白。通过标题、间距和内容分组建立层级，操作入口保持清楚。升级必须保留现有功能、权限条件、系统配置和多语言支持。

本文件记录 2026-09-13 已实施的首页、控制台概览和共享组件基础，以及后续页面应遵循的约束。它不表示所有控制台页面已经完成升级或验收。品牌显示名称使用系统名称配置；默认系统名采用共享品牌名称，避免页头、页脚和浏览器标题各自硬编码不同名字。当前仍发现 main.tsx、登录与助手部分位置硬编码 LMM Forge，品牌一致性尚待后续整合。

## Colors

使用语义变量，不在页面中复制品牌色值。原始颜色由 `apps/web/src/styles/forge-tokens.css` 管理，默认主题由 `theme.css` 映射，主题预设由 `theme-presets.css` 管理。

- 暖白基础色为 `--forge-paper-light`，墨黑基础色为 `--forge-ink-light`；默认亮色主题的背景、主文字、主操作使用这组颜色。
- 默认暗色主题的主操作使用浅色前景配深色文字。公共 Forge 页面通过自己的亮暗色映射设置背景和表面；不能据此推断所有控制台背景已完全一致。
- 次要说明使用 `--muted-foreground`，边界使用 `--border`，焦点使用 `--ring`。
- 成功、警告、提示、错误保留 `--success`、`--warning`、`--info`、`--destructive` 及配套前景色。暖白墨黑不要求把状态色、图表序列或支付品牌标识灰度化。
- 自定义主题仍有效。公共 Forge 页面有自己的语义变量映射；控制台组件必须接受所处主题的变量，不应强制写入亮色背景或黑色文字。

## Typography

正文使用 `--font-body`，默认来自 Public Sans 字体体系；首页第二行主标题及下方探索标题使用 `--font-serif`，保留现有 Lora 和中文回退字体。控制台表单不直接复制首页的大标题排版。

- 首页主标题随视口缩放，窄屏有独立字号范围；翻译增长时允许自然换行。
- 输入框在手机布局中保持至少 `1rem`，默认根字号下为 16px，避免重新引入聚焦放大问题。不要用页面 CSS 覆盖为更小字号。
- 接口地址、模型标识和代码保留原有结构与等宽排版。说明文案使用现有翻译键；新增文案通过项目 i18n 同步流程进入各语言。

## Layout

首页已实施的内容顺序：桌面首屏左侧介绍和主要入口、右侧助手；下方显示接入地址及指南入口；随后是三个接入步骤和代码示例、目的地链接、可展开的账户与审核说明。

- 首页内容最大宽度为 `88rem`，水平留白为 `clamp(1.25rem, 5vw, 5rem)`，章节间距为 `clamp(4rem, 10vw, 9rem)`。
- `58rem` 以下，首屏、接入区和探索区变为单列；`30rem` 以下进一步调整标题、代码容器和标签内边距。
- 代码块在自身内部横向滚动，不撑宽整页；网格子项保留 `min-width: 0`。
- 设置表单保持 `lg` 双列、小屏单列。文本域、开关及声明为完整宽度的内容跨列；共享网格采用水平 `gap-x-10`、垂直 `gap-y-8`。
- 分组容器采用 flex 间距。调整子项间距时使用 `gap-*`，不要再叠加 `space-y-*`。

后续升级应按下表逐类推进，每类完成真实流程验证后再记录为已验收：

| 范围 | 实施重点 | 验收动作 |
| --- | --- | --- |
| 公共页面与导航 | 定价、指南、挑战、安全页的布局、文字和公共壳层一致性 | 检查导航配置、登录要求、品牌名称、亮暗主题和长翻译 |
| 账户与接入流程 | 登录、注册、审核状态、入门指引 | 覆盖匿名、待审批、已开通状态及跳转后的任务连续性 |
| 工作台与助手 | 导航、消息、结果、错误和加载状态 | 验证发送、流式结果、键盘操作、滚动位置和窄屏输入 |
| 钱包与付费工具 | 金额、余额、订单状态及主次操作 | 验证报价、确认、成功、失败和恢复流程，不能只检查静态卡片 |
| 表格与管理设置 | 密集信息、筛选、分组、批量操作、保存反馈 | 验证筛选及提交、错误定位、弹层焦点和小屏信息完整性 |

## Elevation & Depth

普通内容优先用留白、轻微表面色差和必要的分隔线分组。无边框纸面卡片不使用阴影或整体悬浮位移。需要明确区分的独立区域可以保留有边框卡片。

弹窗、菜单、可编辑输入等交互边界不能因减少装饰而失去识别性。当前升级没有统一删除全站边框或阴影；后续逐组件判断其用途。

## Shapes

共享组件保留既有圆角体系。首页主要操作使用胶囊形，代码区域采用轻圆角，助手输入区域使用底边线并在聚焦时显示外轮廓。不要将首页输入样式推广为所有表单的默认样式。

## Components

- `Card` 默认仍是 `variant="outlined"`；`variant="paper"` 去除边框和阴影。
- `TitledCard` 默认 `appearance="paper"`，并通过 `data-card-hover="false"` 禁用全局卡片位移。`appearance="outlined"` 保留卡片边界及标题分隔线。标题和正文水平内边距一致，默认 16px、`sm` 以上 24px；调用方显式覆盖时也应对齐。
- `SettingsControlGroup` 使用底部分隔线和纵向留白。现有日志清理、OAuth 预设、模型价格输入的自定义间距已改为 `gap-3`，避免与容器间距相加。
- 首页助手保留输入校验、敏感内容遮蔽、预设问题、登录转接及不同账户状态的目标页面。不可通过隐藏这些入口实现简化。
- 代码预览保留 Chat、API、Claude、Gemini 四种完整请求示例及复制操作。标签支持方向键、Home、End，使用一个 Tab 停靠点和关联的 tabpanel；代码区域可通过键盘访问。
- Security 目的地读取 `useTopNavLinks`：关闭时不显示，要求登录时携带 `/security` 返回地址进入登录页。不要新增绕过配置的静态入口。
- 审核和购买条件放入原生 `details/summary`，保留键盘展开及完整说明。首屏仍明确提示付款不会解锁开发者权限。
- `ForgePublicShell` 和 Footer 尊重系统名称配置；新增显示名称时复用配置和共享品牌常量。

首页移除了 GPU 装饰及硬编码模型轮播。滚动效果只应用于部分章节标题，以 CSS view timeline 渐进增强；不支持时内容正常显示，减少动态效果偏好下关闭动画和过渡。后续不要加入必须播放完动画才能访问的内容。

### 已有验证证据与边界

以下渲染证据由本次实施主线程提供，源码修复另经只读复核：

- 新首页已实际渲染亮色和暗色模式。
- 窄屏实际 CSS 宽度为 386px，页面 `scrollWidth` 同为 386px，助手输入字号为 16px；代码块横向滚动发生在自身内部。
- 实际 `TitledCard` 样例已在亮色及 underground 自定义暗色主题渲染：paper 边框为 0、hover 标记关闭，outlined 保留边界，样例标题及正文左右内边距均为 24px。
- 配置入口、助手流程和代码标签的回归用例保留在 `forge-home.test.tsx`；测试是否通过及具体命令以本次执行记录为准，文件存在本身不等于验证通过。

这些证据只覆盖当前首页和组件基础，不证明所有控制台流程、所有主题或所有手机浏览器已经验收，也不代表真实 iPhone 聚焦行为、真实付费操作或线上部署已验证。后续页面应记录视口、主题、账户状态、实际操作和结果，避免把组件样例检查当作整站完成。

## Do's and Don'ts

### 控制台概览与顶栏

- 概览用量和性能区域改为平整分区，去掉嵌套小卡片和进入时的错峰动画。保留真实用量趋势、余额、用量、请求数、余额健康与预计时长；没有实际趋势样本时不绘制占位折线。
- 手机将余额和钱包入口前置，用量采用左右对齐的紧凑行。概览区标题使用正文家族的半粗体，减少密集操作界面中的展示字体。
- 用量失败显示未知与重试，账户 ID 加入缓存键。切换语言后金额单位随当前配置重新格式化。性能 API 的网络错误与 success:false 均呈现失败；空数据提供刷新，不显示绿色动画。只有具有请求数时才使用“按流量排序”，并真正按请求数排序。
- 共享 PanelWrapper 去掉外边框，空状态不再占据完整图表高度；加载和空状态仍保留 headerActions。
- 顶栏导航参与正常 flex 布局，空间不足时内部滚动，焦点框绘制在链接内部。手机顶栏六个入口均为 44px；助手仍可从原有浮动入口打开。默认主题色样同步为暖白与墨黑。
- 本地真实控制台已检查默认亮暗、中文/法语、320px 和 386px 手机宽度，以及 1024px/1280px 桌面宽度；320px 页宽与 scrollWidth 相同，顶栏最右按钮在 312px 内。1024px 法语导航键盘焦点可见，导航高度 40px，没有顶栏外溢。
- 10 项相关回归、类型检查、lint 与生产构建通过；最终首屏 gzip 424,802 字节，预算 786,432 字节。设计扫描未报告本批问题。
- 浏览器使用 loopback persona 实验环境，数据为模拟值。其尚未模拟的 ratio-notifications 和语言保存请求被测试层阻止，不能据此判定对应生产接口失败，也不把本次页面验证当作真实业务验收。

### 后续约束

- 用语义颜色、对齐和间距组织界面；逐页保留功能和权限判断。
- 保留键盘焦点、图标按钮名称、加载与错误反馈；状态同时用文字表达。
- 每批改动检查桌面及窄屏、亮暗主题；涉及共享组件时补充一个自定义主题和实际业务页面。
- 不把横向溢出简单裁掉：代码允许内部滚动，正文、操作和表单应正常换行或重排。
- 不为统一外观删除模型、设置、筛选、审核说明或恢复路径，不用硬编码内容代替服务器配置。
- 不将首页大留白机械复制到密集操作页面，也不将当前验证范围扩大为全站升级完成。
