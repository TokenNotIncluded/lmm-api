# LMM 静态 Web 控制台

保留 React/TypeScript，产物为浏览器静态文件，无独立产品后端进程。contracts 为所用 Core/扩展 JSON、权限、价格和错误语义规范；浏览器从服务端取真实 capabilities 与用户授权，不根据菜单、自报角色或本地缓存决定权限/扣款。构建工具、React、路由、查询、表格、表单、i18next、图形与字体库属于可复用外部工程依赖，锁定实际版本并保留许可证，不要求重建这些库。

覆盖首页、公开定价与模型详情、登录/注册/OAuth/挑战/恢复、setup、公告、个人/团队/API Key/钱包/账单/用量、开发者、模型聊天与测试、商店商品/订单/购物车/客服、工具与助手市场/执行，以及管理员和运营功能。按实际 capabilities 处理未启用或待完成页面，不将路由存在当成功能已可用。保留法律/隐私/退款页和错误页面；服务未配置或不可用时显示准确阻塞。

设计方向见 DESIGN.md。品牌 LMM、图标与图形须保留归属或使用获许可重建；不要复制未授权素材。支持简体中文、繁体中文、英语、法语、俄语、日语、越南语，用户语言归一化，document lang 同步，数字、时间和金额单位明确，不因翻译漏项改变权限或钱的含义。

所有重要页面需要正常、加载、空、失败、无权限、依赖关闭和重试状态；金额未知不得显示为 0，付款/退款须可审阅预览与明确确认。撤权、logout 后清除合适的会话状态，不让陈旧数据绕过服务端。敏感信息不进入 URL、遥测或日志。

为窄屏和桌面设计清晰层级，导航/表格/对话/表单不横向溢出；支持键盘、可见焦点、语义标签和降低动态效果。首页粒子/轮播、动效、复杂图表应服从可访问性与性能，具体像素与动画参数未做视觉观察，不当作已测要求。

最低浏览器版本、截图基准、字体实际渲染和性能预算未知。后续使用固定真实后端版本，逐页面执行 ACCEPTANCE.md；组件/构建测试不证明完整业务行为。

管理员全站财务从真实 Core 财务接口读取，使用响应声明的固定归一化单位（每 USD 500000 credits）解释累计使用与全站余额。钱包当前账本单位、公开点数面值及其配置缺失不改变这些统计值的单位；美元显示不能依赖钱包当前换算基准。保留钱包币种选择，但人民币折算只使用已确认汇率，缺少汇率保持未知；选择 credits 时保留精确归一化整数。大于 JavaScript 安全整数范围及负余额不经浮点损失精度。现金原币种的原付款、退款和净额分别列示，LDC 单列；未确认或非法来源保留醒目计数，权限失败、来源缺失和读取失败不伪造零值。

## 定价目录、筛选与排序

目录使用服务端的模型和厂商元信息；列表分组、厂商筛选、图标与详情保持一致。不得用任意子串推断厂商，例如 `thinkingmachines/inkling` 不能因为包含 `kling` 被归到快手。旧单体线上目录的问题须修正实际目录来源并独立复验，修改新架构或渠道拉模型 helper 不代表旧站已修复。

Token/按次筛选与侧栏计数共用同一个分类规则：`billing_mode=tiered_expr` 时解析受限表达式，全部输出分支都是 `fixed` 的按次归类，任何 token 价格分支归 Token；标签中的 `fixed` 字样不能影响分类。语法错误、未知版本、未知函数或未提供表达式回退 `quota_type`，其他计费模式不误读表达式，上游成本单独保留。

提供输入价格、输出价格、每次请求价格分别升序与降序；Token 价格单位统一为 USD/百万 token，每次请求为 USD/次，显式维度只比较对应单位。读取 schema v2 的 USD 实际价格，不能从旧倍率重算。选定分组后比较该分组已计算的价格，不重复乘倍率；该分组缺价不能借用其他分组或基础价。合法 0 表示免费；缺失、负数、非有限值、schema/币种不匹配、上游成本比例以及需要请求上下文的动态表达式均不可比较，在两个方向都稳定排末尾。同价保留原顺序，不原地改变目录输入。没有可信固定报价时，不用首个动态 tier 或任务样例总价冒充模型的固定单价。

保留既有 `price-low` / `price-high` URL 的综合排序行为和标签；新增加的六种显式价格维度有独立 URL 值。排序选择、刷新和历史导航保持一致。七语言文案完整，较长菜单文本应换行且不超出窄屏。

邮箱流程使用 Core 的验证码申请、注册、当前会话绑定及密码重置接口。验证码/重置请求的接纳提示保留“如符合条件”的语义，不承诺 SMTP 或收件箱送达。注册请求保持匿名，不携带当前 bearer，也不自动刷新重放；绑定请求固定发起时的 bearer 与会话，身份变化时拒绝重放。重置页支持配置站点的 `/user/reset#email=...&token=...`，在任何应用脚本或资源初始化前移除地址中的证明，只将原证明用于一次明确的重置提交；不将 reset 成功当作登录或 MFA 完成。真实 DOM/类型检查不替代实际浏览器与 Core、SMTP 的组合验收。

性能页面消费真实原生观测：优先使用服务端 aggregate，分组/趋势按 request_count、success_count、latency_sum_us、ttft_sum_us/ttft_count、output_tokens/throughput_time_us 等实际分子分母合并；不能平均组或模型均值。未知数值保持 null，不以 Number(null)、默认零或绿色成功伪装。availability=partial 时持续展示部分覆盖、采样数和缺样本数，即使列表为空也可见；明确延迟仅为 relay 阶段，吞吐为成功输出除以 relay 总秒，不冒充供应商生成速率。兼容未提供新分母的旧接口，但不能声称旧分支已加权。七语言、模型徽标/详情/比较、仪表盘和状态页对 nullable 值一致。
