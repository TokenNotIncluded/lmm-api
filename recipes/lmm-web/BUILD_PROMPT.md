# LMM 静态 Web 控制台

保留 React/TypeScript，产物为浏览器静态文件，无独立产品后端进程。contracts 为所用 Core/扩展 JSON、权限、价格和错误语义规范；浏览器从服务端取真实 capabilities 与用户授权，不根据菜单、自报角色或本地缓存决定权限/扣款。构建工具、React、路由、查询、表格、表单、i18next、图形与字体库属于可复用外部工程依赖，锁定实际版本并保留许可证，不要求重建这些库。

覆盖首页、公开定价与模型详情、登录/注册/OAuth/挑战/恢复、setup、公告、个人/团队/API Key/钱包/账单/用量、开发者、模型聊天与测试、商店商品/订单/购物车/客服、工具与助手市场/执行，以及管理员和运营功能。按实际 capabilities 处理未启用或待完成页面，不将路由存在当成功能已可用。保留法律/隐私/退款页和错误页面；服务未配置或不可用时显示准确阻塞。

设计方向见 DESIGN.md。品牌 LMM、图标与图形须保留归属或使用获许可重建；不要复制未授权素材。支持简体中文、繁体中文、英语、法语、俄语、日语、越南语，用户语言归一化，document lang 同步，数字、时间和金额单位明确，不因翻译漏项改变权限或钱的含义。

所有重要页面需要正常、加载、空、失败、无权限、依赖关闭和重试状态；金额未知不得显示为 0，付款/退款须可审阅预览与明确确认。撤权、logout 后清除合适的会话状态，不让陈旧数据绕过服务端。敏感信息不进入 URL、遥测或日志。

为窄屏和桌面设计清晰层级，导航/表格/对话/表单不横向溢出；支持键盘、可见焦点、语义标签和降低动态效果。首页粒子/轮播、动效、复杂图表应服从可访问性与性能，具体像素与动画参数未做视觉观察，不当作已测要求。

最低浏览器版本、截图基准、字体实际渲染和性能预算未知。后续使用固定真实后端版本，逐页面执行 ACCEPTANCE.md；组件/构建测试不证明完整业务行为。
