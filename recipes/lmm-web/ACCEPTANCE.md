# Web 验收要求

建立页面×角色×状态清单，至少覆盖首页、定价、登录/OAuth、团队/Key、钱包/账单/用量、聊天、商店/订单/退款、工具/助手、管理员和法律页。

1. 每类真实页面在桌面与窄屏检查加载/空/错误/无权限/能力关闭/正常，记录固定版本与新截图；键盘、焦点、标签和减少动效可用。
2. 七语言选择、浏览器 zh-Hans/zh-Hant 归一化、document lang、翻译完整性、金额/日期/时区可理解；不把未知单位显示为零余额。
3. 真实 Core/扩展下登录/撤销/刷新、个人/团队切换、跨租户拒绝；客户端禁用按钮不能替代后端授权。
4. 模型 SSE 的部分输出、终止错误、取消/断流显示正确，缺失 usage 不展示已完成零费用。
5. 商店购买/支付/退款先展示对象、金额、单位与确认；重复点击/刷新后服务端幂等，最终账本与页面一致。
6. capability 不可用时明确阻塞，不展示假成功；匿名/管理员/开发者/团队角色操作分别验证。
7. 静态分发无需 Node 产品服务；新版本资源缓存与 API 错误不导致白页。负载和包体积先建立实测基线。

本轮未运行浏览器、可访问性、截图或 Web 构建，以上均 NOT RUN。
