# 设计证据与重建方向

初始配方来自源码与文档。2026-10-30 的 HTML-in-Canvas 美化由用户直接要求；以下区分设计合同与当次验证。

- 身份：品牌为 LMM API / Language Model Mesh，中文口号「连接模型与工具，让智能自由流动」；有独立 Logo、首页粒子雕塑和轮播相关源码/指导。
- 构成：静态 React 应用，有路由化公开页、认证用户功能、后台管理、商店/助手/工具市场等，采用查询缓存、表格、表单与语义组件。
- 依赖清单含 Public Sans 与 Lora 可变字体、Tailwind、Base UI、图标与 Three；清单不能证明其实际全局应用或最终视觉效果。
- 布局建议：公开首页与业务工作台分别按内容任务设计；密集数据表提供必要筛选/分页；订单和资金动作突出金额、状态、对象与确认。建议是重建推断，不是旧 UI 像素事实。
- 色值、间距、字体尺寸、图形曲线、深浅主题实际覆盖与动效时序：未验证，后续以授权截图/浏览器观测冻结基准，不套通用 AI 仪表盘。
- 所有新建/替换素材说明来源和许可证；构建阶段不静默下载不可追溯设计资源。


## HTML-in-Canvas 设计合同（2026-10-30）

页面首先是一组清晰可操作的文字、数据和控件；Canvas 为首页的模型连接图提供视觉表现。默认浅色采用暖白，暗色采用炭黑，少量香槟金强调焦点、品牌细节和图表主系列。用留白、字重与细分隔线建立层级，避免每个区块重复包裹边框。现有主题、字体、密度与圆角偏好继续生效。

首页保留五个既有章节、租户品牌与真实账户相关操作，新增「一个入口」的交互连接场景。节点保持可选择、可访问的 HTML 链接；支持时使用正式 HTML-in-Canvas `content="drawable"`、`drawable`、`drawElementImage()` 接口，在 `paint` 时绘制。通过能力检测选择渲染路径；不支持或绘制失败时，同一内容在正常 DOM 中完整显示。自定义跨域 Logo 留在普通图像层。

场景响应实际布局和屏幕像素密度；画布尺寸不变时不重新分配。离屏、隐藏标签页、手动暂停和减少动态效果时停止指针反馈；清理自己注册的监听器与观察器。静止时不启动永久逐帧循环。模型连接图不发送模型请求，不显示虚构吞吐、可用率或账户指标。

控制台以数据为中心：余额与关键数值更清晰，统计用细线分栏；表格保留行比较、筛选、分页与状态。按钮、输入框、对话框、空状态和加载状态统一间距；不让数据表逐行延迟出现或使不可操作卡片悬浮。导航、表单与触控区保留键盘焦点和安全区。

认证页采用暖白表单与炭黑交互面板，移动端保留可折叠游戏。价格页突出实际模型、价格、币种和单位，指南页采用宽松阅读区；保留现有语言、登录方式、权限、会话、支付确认及错误恢复行为。HTML-in-Canvas 不改变这些业务接口。
