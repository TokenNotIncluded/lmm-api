# LMM 架构调整交付报告

日期：2026-11-17（UTC）  
状态：**实现、所列范围验证及源码引用更新已完成**  
源码提交：`94b5cf32b26ee8daa11d8453882f95a38dc959bc`  
父仓库源码锁定提交：`82c06110ef97b990bfd72382b5d8af067a364c1b`

本轮完成三项架构调整：取消开发者资格门槛，移除平台信任等级，移除 LMM 与 Pi 内置远程控制。源码、插件和六份需求及验收文档已经增量提交推送；最终 Core 验证固定在上列源码提交，父仓库已锁定相同版本。

## 一、三项需求的实际变化

**普通用户直接使用。** 有效账号登录后，普通功能按实际资源权限和服务可用性开放，不再要求开发者审批、付费激活或等级提升。API Key、配置引导、助手和模型入口同步清理旧资格判断；陈旧缓存中的 `developer=false` 也不能重新阻塞正常流程。模型组没有显式分配时使用可用默认组；存在显式分配时只使用获准且启用的组，明确禁用不能通过默认回退重新开放。

**平台信任等级退出运行规则。** 当前准入、报价、折扣和奖励不再按平台等级决定；等级设置、权益展示、策略编辑及专用编辑凭据入口随之移除。模型、渠道、分组和用量配置继续决定实际价格，按用量分段计价保留。签到采用统一基础奖励范围和独立日上限。新写入的签到策略不再包含等级倍率；已有策略行保持原文以便审计，当前奖励执行不再应用旧等级倍率。旧五项日上限配置在兼容读取时统一折叠为原第五项，不再按用户等级选择。

**内置远控从 LMM 和 Pi 中移除。** 清理覆盖 Core/Go 路由、RPC 与生成协议、Web 页面与工具，以及 Pi 的远控客户端、命令、通信、自动启动和远控 scope。旧远控配置不能重新注册这些能力。Pi 继续提供认证和模型服务；DSH 的 Pi 引用同步更新。远程控制由独立的 ssmcp 项目承担，本轮没有建立 LMM 与 ssmcp 之间的自动连接或桥接。

## 二、保留的授权边界与历史记录

取消资格分层后，每次操作仍须确定当前账号、资源所有者、团队、付款方和可用预算。真实 root/admin 管理权限、MFA/Passkey、会话撤销、账号停用、滥用防护、网络限制和资金校验继续生效。缺少模型路由、供应商配置或可用资金时，页面和接口继续返回真实状态。管理员的普通用户预览保持只读，并与管理员私有数据隔离；真实普通用户会话仍能执行其获准的操作。

历史账务保留当时的金额、冻结价格、折扣、幂等键和结算结果。历史数据库组件、旧字段和必要的重放逻辑用于解释既有记录，不参与新的资格准入。新签到设置不改写旧策略行。LinuxDO 身份提供方的外部验证条件、受信代理与 IP 概念单独保留；这些不是 LMM 平台用户等级。
