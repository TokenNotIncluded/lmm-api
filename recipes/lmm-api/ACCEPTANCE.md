# 集成验收

本文件是重建集成验收入口；完整原始范围见 COMPLETION_SCOPE.md，100% 可用和生产切换证据门槛见 PRODUCTION_ACCEPTANCE.md。每轮实际状态在仓库外绑定输入保存，本配方不把已有局部测试冒充本轮产品通过。

| 场景 | 具体检查 | 通过条件 |
| --- | --- | --- |
| 递归配方 | 对根运行 recipkg check；临时 pack/check/build | 所有递归包为 UTF-8 Markdown、无执行钩子或源码、可完整渲染 |
| 三程序装配 | 独立构建 Core、扩展、CLI 和静态 Web | 三个产品程序，没有额外部署 daemon |
| 独立 Core | 空隔离库经 owner 显式初始化；runtime 启动，Go 完全停止 | 身份可用；经显式配置的合成模型可调用；扩展不阻塞核心 |
| 安装边界 | 普通启动连接空库、错误 schema 或 owner 运行角色 | 明确拒绝，表/角色/序列和数据不被自动修改 |
| 权限 | 个人/团队/管理员/开发者、跨租户与撤权后请求 | 只在合法 scope 执行；菜单可见性不代替后端拒绝 |
| 模型资金 | 明确 actor/payer/报价后预留，重试、重复回调、断流、重启恢复 | 唯一操作、唯一账本；UNKNOWN 不换付款方，不按零用量结算 |
| 扩展商店 | Core+Go 真进程及隔离数据库完成购买、查询、退款与重启恢复 | 记录和账本回读一致；缺少身份/资金权限必拒绝 |
| 支付 | 合成验证后另行授权真实供应商测试回调/退款 | 回调验签、金额币种、重复与乱序处理正确；合成成功不替代真实验收 |
| 数据迁移 | 授权只读源副本、新目标、冻结映射，预览后显式执行 | 各领域逐笔对账、重复可重放、冲突拒绝且无额外写入；不改变原源 |
| Web | 每类页面的加载/空/错/无权限/正常、窄屏键盘、多语言 | 与真实后台联合；未知余额非零，危险资金操作先预览确认 |
| CLI | 按 cli 配方跑离线/网络/凭据库/非交互测试 | 不支持动作有非零失败及原因，不返回空成功 |
| 公开状态 | health/ready 与 health/model-ready、状态 capabilities | 准确区分模型/支付/身份能力；关闭模型就绪不报成功 |
| 资源 | 固定源码/工具/设备/数据测量 SSE、慢请求、扩展停机、恢复 | 发布真实基线与重复测量；未知预算不伪造通过 |
| 交付 | 核对源码 SHA、依赖、归档、运行版本与恢复材料 | 本地自测、独立验收、推送、发布、部署分别报告 |
| Issue 闭环 | 读取 ISSUE_MAINTENANCE.md，核对源码修复、相关测试、配方版本和源码 gitlink | 只有对应范围已解决才关闭 issue；旧 PR 的剩余验收继续可追踪 |
| 质量证据 | 同工作区/同 Git 状态但不同暂存 blob；暂存修改后工作区还原；删除/重命名/模式变更/未合并索引 | 摘要绑定真实暂存内容；扫描不漏 staged-only；执行中变更使证据失效；full 计划保留 Mocklab selftest |

未完成能力继续列为 BLOCKED/NOT RUN。不得降低断言、仅用成功 mock，或将历史验收计入新候选。
