# 最终验收合同

[PRODUCT_REQUIREMENTS.md](PRODUCT_REQUIREMENTS.md) 及组件配方的每项必需行为，都应有同一最终候选对应的证据。源码存在、配方结构、测试数量或健康接口不能代替业务完成，也不能把领域平均为完成百分比。此文件定义通过条件；动态状态只维护[源码进度列表](https://github.com/TokenNotIncluded/lmm-api-source/blob/main/docs/progress.md)，不提供生产操作授权。

## 迁移与切换演练

1. 固定需求、候选源码、工具链、依赖、Core/Go/CLI/Web 制品和 schema，核实实际进程身份。相同 schema-manifest 只证明安装结构一致，不能证明二进制来自当前完整源码。
2. 固定授权只读来源、归档、表/字段/行/序列/单位/UTC、完整身份映射和目标实例。原秘密留私有归档；派生计划的任意字段或 metadata 不得夹带已知 bearer，异常/报告不能泄露原材料。
3. 逐领域对账。源目标同样非法的 Key 限制字段不能标 matched；stored facts 相符仍须证明完整导出范围、目标来源、实际权限和单位。未知事实不按零、禁用或默认单位补齐。
4. 迁移按身份/console、资金/Key/订阅/历史来源、各独立业务库的依赖顺序执行，同一归档与映射，审批 activation-last。每批原 SQL/原 ID 固定；精确重放、冲突拒绝、无关表/序列及全部金额守恒。在后续批次或应用开始写入后关闭早期严格回放，不能回头重做。
5. 最终 writer fence、旧 worker 和回调/请求/退款 drain 必须真实读回；active writers=0、unknown liabilities=0。已知未结算/持续权益在同一原操作保留恢复，不重复扣款。死 holder 接管须有死亡证明和一次 CAS。
6. 实际还原匹配的加密备份，核身份/资金/Key/订阅/历史/序列/角色与 ACL，并重启业务验证。说明切换后新账本的恢复方法；回退二进制不等于数据可逆。独立升级历史及外围栏不能随目标旧备份回退。
7. 在新隔离候选完整演练边缘路由/回调切换、业务、重启、故障与恢复，保存实际运行配置和制品身份。目标生产主机/服务/包/凭据引用/路径与约束需在授权后读回，本地通过不推定远端满足条件。
8. 预检拒绝 `extensions.host_credential="absent"` 及每项必要权限缺失。`core-cutover-preflight` 的 READY/safe_to_cutover 仅说明受信任输入的合同一致性；必须核引用证据、目标、时效和最终组合，手写布尔值或形状正确的 hash 不是切流证明。
9. 生产执行须有用户明确授权，使用同一已审核候选，切换后观察关键业务、进程/版本与恢复条件。未切换时只报告已证明的前提和未执行范围，不称已上线。

## 资源与新旧性能

| 范围 | 硬条件 |
| --- | --- |
| 单 Core | 1 CPU、256 MiB cgroup 硬限额 |
| Core+Go 产品组 | 共享 1 CPU、512 MiB；数据库/生成器/合成上游预算单列 |
| 整机目标 | 1C1G 下代表性业务另验，产品组通过不抵扣整机 |
| 完整 HTTP/SSE 负载 | 60秒预热、300秒稳态、60秒过载、60秒恢复、60秒排空；正常5 RPS、80% JSON/20% SSE |
| 正常阶段门槛 | 完整成功率≥99%、P95≤1秒、P99≤2秒，并满足完整响应与账本断言 |

同时观察慢消费者/取消、过载、恢复/排空、内存增长、FD/连接、数据库连接及 cgroup 事件。不能靠全部 503、缩功能、提前关闭保留客户端或抬高阈值通过。新环境记录同等或更明确的 workload 与门槛。

与旧架构比较使用可追溯的优化构建、相同 CPU/内存、数据规模、功能/计费语义、预热和请求负载。分别报告成功/拒绝/超时、吞吐、P50/P95/P99、常驻/峰值 RSS/PSS、长稳与故障恢复；保存原始采样。未实测不写提升百分比，debug/合成结果不冒充生产性能。

## 记录与关闭条件

每项证据记录固定输入、expected/observed、命令/cwd、真实工具版本、退出码、日志、数据库/进程/页面身份和独立复验人。PASS/FAIL/BLOCKED/NOT RUN 明确区分；合成单元、真实 PG、实际 OS 进程、浏览器、外部服务和生产分别记载。证据复核不称为独立重跑，对象重建不称为 OS 重启。

必要项未执行、证据缺失、输入漂移或未解决的严重资金/权限问题，整体保持未完成。质量债务按自己的退出条件映射真实证据、补验并审查，不能延后期限/降等级/手填回执消除阻断。保留失败和跳过，不删断言、不用 success-only mock 或无依据 skip 凑通过。

历史任务原文与既往回执的来源见 [PRODUCT_REQUIREMENTS.md](PRODUCT_REQUIREMENTS.md#历史保全)；当前进度只在源码列表更新。
