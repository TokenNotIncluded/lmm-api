# DP-27 本地验收报告

结论：交付了可运行的实验代码、已签名的独立健康探针产物，以及本地分发证据。**业务镜像和 1c1g 更新成本尚未验收，不能批准正式集成。**

## 代码与环境

基线：`72667564c0431754d4856dc2e0db55f360bd2745`。目标：`wip/rust-core-go-extensions`，关联 #675。
探针源代码提交：`2f5b2c3574d3f7984b3eef16f4e35f33d2830c58`。实验工具及最终证据另随本地补丁交付。
GitHub 只读核对了构建入口、依赖、生成器和根树。由于 Git 网络解析失败，未完整克隆。恢复了与远程 SHA 完全一致的基线提交和根树对象引用，并在该基线上新增实验目录；不是一个可以构建业务服务的完整工作副本。

本机：Linux 6.18.44 / amd64，Go 1.23.2；容器 CPU 配额 4 核，内存限制 4 GiB。
被测子进程绑到 CPU 0。没有 Docker、Rust、Bun 或 UPX。这不是 1c1g 机器。
每项启动/解压重复七次。下表为中位耗时。测量工具空操作耗时中位数 2.137 ms；表中未减去它，不能据亚毫秒差异宣称性能胜出。RSS 来自 GNU time 的被测命令，不把 Python 父进程内存当作业务进程内存。

## 独立探针：真实编译结果

| 实现 | 文件字节 | 启动并完成本机健康检查 / ms | 最大 RSS / KiB |
|---|---:|---:|---:|
| 标准 HTTP 客户端 | 5,132,440 | 2.497 | 5,228 |
| 有界状态行及头部读取 | 1,994,904 | 2.293 | 2,436 |

探针文件减少 3,137,536 字节，约 61.13%。这不是 core/extensions 镜像的节省；与现有 curl 及其动态库的真实镜像对比仍未进行。探针的测试覆盖合法状态、错误状态、跳转、取消和残缺 HTTP 头部。

## 暂存空间：差分并不必然更省磁盘

保留旧探针文件，不修改 current 指针；按文件已分配块分阶段采样，并按设备和 inode 去重硬链接。不是 Docker 快照器峰值，也没有模拟整台服务节点的全部磁盘。

| 方法 | 包字节 | 暂存目录采样峰值 / 字节（含旧文件） | 相对传输前新增 / 字节 |
|---|---:|---:|---:|
| gzip-6 | 876,095 | 4,882,432 | 2,875,392 |
| zstd-patch | 420 | 6,008,832 | 4,001,792 |

差分的网络包很小，但本原型为避免读取变化中的旧文件，会保留一个经过校验的私有基准副本，因此峰值空间高于本次完整 gzip 包。空间预检另外保留 16 MiB 安全余量，不把这部分当作实测分配。

## 失败保护和依赖选择

56 项 Python 测试通过；独立 Go 探针 race 测试通过。这些不是 main 或微内核完整业务验收。
已执行：错误签名/公钥、清单篡改、组件/源提交不匹配、错误架构及 ELF、截断/损坏包、解压超过声明大小、错误最终摘要、错误差分基准、并发锁、已有就绪文件被损坏。
网络故障为真实回环 TCP 中途断开；磁盘故障为空间预检和阶段注入 ENOSPC，不是填满真实磁盘。失败后旧文件和 current 指针不变。无运行版本切换接口，未证明真实服务的持续可用或回滚切流。
依赖测试确认 Go 普通变更仅重建 extensions；前端变更仅重建 web；Protobuf/已生成绑定变化覆盖 core、core-admin、extensions；Rust CLI 独立。未知共享依赖阻止自动选择。真实 git 改名也验证旧、新路径同时处理。
